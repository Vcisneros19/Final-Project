# Personal Portfolio Website

## Project Overview

This project was created for CMPA 3301 as my final project. The purpose of this project is to create a simple personal portfolio website while also demonstrating the project management and web development skills I learned throughout the course.

The website introduces who I am, my education, professional interests, skills, and future career goals. I am currently pursuing a degree in Computing Applications with a minor in Mathematics. My long-term goal is to build a career in a STEM-related field, with interests in data analysis, software development, and similar technology careers.

This project also demonstrates how planning, risk management, documentation, and reflection can be used when completing a digital project. The repository includes the website files along with the planning documents used to guide the project.
