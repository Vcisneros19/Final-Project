# Project Retrospective

## What Went Well?

One of the things that went well during this project was having a better understanding of project management compared to when I started the course. Before this course, I understood the basic idea of planning and completing a project, but I did not fully understand everything that goes into managing one. Creating a scope statement, identifying risks, and breaking the project into smaller tasks made the final project easier to organize.

I also became more comfortable working with HTML and CSS. I was able to create multiple pages, connect them together, and use one stylesheet to keep the website consistent. Another thing that went well was being able to use work from previous assignments as a starting point instead of beginning the final project completely from scratch.

## What Went Wrong?

My biggest struggle throughout the course was GitHub because I had never really used it before. Repositories, commits, file locations, and GitHub Pages were confusing at first. There were times when I made changes but could not immediately see them on the live website, which made me think something was wrong with my code.

Time management was also challenging because I had to balance this course with other classes and my work schedule. Sometimes this caused me to work on assignments closer to the deadline than I wanted. When that happened, troubleshooting became more stressful because I had less time to figure out what went wrong.

## What Would I Do Differently?

If I completed a similar project again, I would start earlier and divide the project into smaller stages from the beginning. I would create the repository structure first, then complete the planning documents, website content, styling, testing, and final review separately. This would give me more time to troubleshoot problems without feeling rushed.

I would also spend more time learning GitHub before starting a larger project. This course showed me that mistakes are part of learning unfamiliar tools. One idea I took from *Range* is that different experiences and skills can help someone become more adaptable. Even though GitHub was difficult for me at first, learning it gave me another skill that I can continue using in future classes and professional projects.

Overall, this project helped me understand that building the website is only one part of completing a digital project. Planning, communication, risk management, organization, testing, and reflection are also important parts of producing a successful final result.
